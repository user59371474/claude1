# 01. 브리프 — kimdongjunai

작성일: 2026-09-29 · 상태: 확정 (2026-09-29, 방향 수정 반영)

## 확정된 방향 (사용자 결정, 2026-09-29)

> "말을 줄이고 이미지로 압도하자. 의뢰자 무시하고 멋진 것만 신경 써."

- 텍스트는 극단적으로 줄인다. 프로젝트 라벨·코드·연도 정도만 남긴다.
- 가격 안내, 서비스 설명, 의뢰 시 안내 문구는 **넣지 않는다**.
- 의뢰 동선은 최소한만 유지: 헤더/푸터의 작은 `CONTACT`·`INSTAGRAM` 링크. 하단 고정 CTA 없음.
- 판단 기준은 전환율이 아니라 **미감과 브랜드 인상**.

## 한 줄 정의

**디자인·영상·웹을 만드는 크리에이터 kimdongjunai의 미감과 작업을 보여주고, 작업 의뢰로 이어지게 하는 브랜딩 포트폴리오 사이트.**

## 타깃 페르소나

### A. 브랜드 담당자 "지현" (34세, 스타트업 마케팅 리드)
- 인스타그램에서 작업을 보고 들어옴. 이동 중엔 **휴대폰**, 검토·공유는 **랩탑**.
- 알고 싶은 것: 이 사람의 결과물 퀄리티, 우리 브랜드와 맞는 톤인지, 대략적인 비용과 기간.
- 행동: 포트폴리오 2~3개를 깊게 보고, 링크를 팀에 공유한 뒤 문의.

### B. 개인 사업자 "성훈" (41세, 카페·편집숍 운영)
- 로고, 홍보 영상, 홈페이지를 한 번에 맡길 사람을 찾음. 주로 **휴대폰**.
- 알고 싶은 것: 한 사람에게 여러 작업을 맡길 수 있는지, 가격이 부담 없는지, 연락 방법.
- 행동: 짧게 훑고 마음에 들면 바로 DM이나 카톡으로 연락.

## 목적과 CTA

- **주 목적:** 브랜딩. 첫 화면에서 "이 사람 감각 좋다"는 인상을 주는 게 1순위.
- **핵심 행동:** 작업을 보는 것 자체. 연락은 작고 절제된 `CONTACT`(이메일)·`INSTAGRAM` 링크로만.
- 필요 기능이 없다고 하셔서 **서버·폼 없이 외부 링크로 의뢰를 받는 정적 사이트**를 기본으로 제안합니다. 나중에 문의 폼이 필요해지면 Cloudflare Workers로 추가할 수 있어요.

## 기능 목록

### 필수
- 포트폴리오 목록 + 분야 필터 (디자인 / 영상 / 웹)
- 프로젝트 상세 페이지 (이미지·영상 임베드, 클라이언트, 역할, 연도)
- 영상 재생 (YouTube/Vimeo 임베드 또는 자체 mp4, 지연 로딩)
- 헤더·푸터의 작은 CONTACT / INSTAGRAM 링크
- 반응형 (모바일 우선, 랩탑 최적화)
- SEO·공유 미리보기 (OG 이미지, 카카오톡·인스타 공유 대비)

### 선택
- 한/영 병기 (레퍼런스처럼 영문 중심 표기를 쓰면 브랜드 인상에 유리)
- 간단한 의뢰 폼 (Workers + 이메일 전송)
- 인스타그램 최신 게시물 노출

## 사이트맵

| 페이지 | 경로 | 목적 |
|---|---|---|
| 메인 | `/` | 첫인상으로 브랜딩. 대표작 몇 개와 의뢰 버튼 |
| 작업 목록 | `/work` | 분야별 전체 포트폴리오 탐색 |
| 작업 상세 | `/work/[프로젝트]` | 결과물을 크게 보여주고 다음 작업·의뢰로 연결 |
| 소개 | `/about` | 이름, 분야, 클라이언트 목록 몇 줄. 긴 설명 없음 |
| 연락 | `/contact` | 이메일·인스타그램 링크만 |
| 404 | `/404` | 브랜드 톤을 유지한 안내 + 메인·작업으로 이동 |
