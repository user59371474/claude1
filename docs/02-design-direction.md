확정일: 2026-09-29 · 토큰: `src/styles/tokens.css` · 비교 시안: `docs/moodboard.html`

## 무드 키워드
압도적인 · 절제된 · 아카이브적인 · 차가운 · 대담한

## 컨셉
**ARCHIVE** — 작업을 컴퓨터 파일 시스템처럼 보여주는 흑백 아카이브. 빨강 하나로 방점을 찍는다.
레퍼런스: public---domain.com (OS·폴더 구조, 흑백 + 빨강), yeezy.com (텍스트 최소화, 이미지 그리드)

## 컬러

| 토큰 | HEX | 용도 |
|---|---|---|
| `--color-paper` | #FFFFFF | 배경 |
| `--color-ink` | #0A0A0A | 글자, 선, 반전(hover) 배경 |
| `--color-mute` | #6B6B6B | 보조 글자 (연도, 분류) |
| `--color-line` | #DADADA | 그리드 틈, 구분선. 글자 금지 |
| `--color-disabled` | #8C8C8C | 비활성·장식 전용 |
| `--color-signal` | #FF2A00 | 커서, 상태 점, 면. 그 위 글자는 ink |
| `--color-signal-text` | #E62600 | 흰 배경 위 빨간 글자가 꼭 필요할 때만 |

**대비 점검 (WCAG AA 4.5:1)**
- ink / paper 19.8:1 · mute / paper 5.3:1 · signal-text / paper 4.5:1 · ink / signal 5.3:1 — 통과
- 모드보드의 회색 #8C8C8C(3.4:1)와 빨강 #FF2A00(3.8:1)은 글자로는 미달이라 역할을 나눴다.

## 타이포그래피

| 역할 | 폰트 | 라이선스 |
|---|---|---|
| 영문·숫자·라벨·파일명·제목 | IBM Plex Mono 400/500 | SIL OFL 1.1 (상업 사용·웹폰트 임베드 가능) |
| 한글 본문 | IBM Plex Sans KR 400/500 | SIL OFL 1.1 |

- 스케일: 12(대문자 라벨 전용) / 14 / 16(본문 최소) / 20 / 28 / 40 / 40→96(디스플레이)
- 라벨은 대문자 + 자간 0.06em. 디스플레이는 자간 -0.02em, 행간 1.05.
- 한글은 짧은 한 줄 이하. 긴 문장은 쓰지 않는다.

## 레이아웃 성격
- OS 창 구조: 상단 타이틀 바(경로 `KIMDONGJUNAI/WORK/`), 하단 상태 바(항목 수, 연도).
- 촘촘한 파일 그리드, 1px 선과 1px 틈으로 칸을 나눔. 여백 대신 선으로 정리.
- 모든 모서리 직각(radius 0), 그림자 없음.

## 이미지·그래픽 톤
- 작업물은 정사각·4:5 썸네일로 균일하게 자름. 목록에서는 원본 색 그대로, 크기로 압도.
- 프로젝트 이름은 `KDJ_001.MOV`, `KDJ_002.IDN`처럼 번호 + 확장자(분야). MOV=영상, IDN=아이덴티티·디자인, WEB=웹.
- 아이콘은 쓰지 않고 문자(≡, ●, →, _)로 대체.

## 모션
- 부드러운 이징 없이 즉시 전환(`steps(1)`). 호버 시 흑백 반전.
- 깜빡이는 빨간 커서 하나가 시그니처.
- `prefers-reduced-motion`이면 커서 깜빡임 중지.

## 타깃 적합성 (30~40대, 랩탑·휴대폰)
- 흰 바탕·검정 글자로 대비 충분. 본문 16px 이상, 12px은 라벨에만.
- 모노 폰트는 폭이 넓어 모바일에서 파일명이 길면 말줄임 처리.
- 모션이 거의 없어 저사양 휴대폰에서도 가볍다.
