# 03. UX/UI 명세

작성일: 2026-09-29 · 상태: 승인 대기 · 시안: `docs/prototype/index.html` (폭 비교: `docs/prototype/preview.html`)

## 원칙
- 모바일 우선. 기준 폭 375 / 768 / 1280px, 콘텐츠 최대 폭 1440px.
- 터치 영역 44px 이상, 본문 16px 이상, 대비 WCAG AA, 키보드 포커스 표시(빨간 링), 모든 이미지 alt.
- 연락 링크(CONTACT)는 헤더에 고정되어 첫 화면과 스크롤 중 항상 닿는다. 하단 고정 CTA는 두지 않는다(브리프 결정).
- 내비게이션: 모바일은 ≡ 버튼 → 전체 화면 메뉴, 768px 이상은 상단 가로 메뉴.
- 텍스트는 파일명·분류·연도 수준으로 최소화.

## 페이지별 섹션

### 메인 `/`
1. **타이틀 바**(고정): 경로 `KIMDONGJUNAI/`, 메뉴 WORK · INFO · CONTACT · INSTAGRAM
2. **히어로**: `~/kimdongjunai/archive_2026` + 깜빡이는 빨간 커서, 바로 아래 대표작 1개를 크게(영상이면 음소거 자동 재생, 포스터 이미지 먼저)
3. **인덱스**: 분야 폴더 탭(ALL / MOV / IDN / WEB) + 보기 전환(GRID / LIST), 파일 그리드
4. **상태 바(푸터)**: `24 ITEMS`, 연락처(이메일 텍스트), INSTAGRAM, © 2026

### 작업 목록 `/work`
메인 인덱스와 같은 구성, 히어로 없이 전체 목록. 탭 상태는 URL 해시(`#mov`)로 공유 가능.

### 작업 상세 `/work/[slug]`
1. 타이틀 바: `KIMDONGJUNAI/WORK/KDJ_014.MOV`
2. 미디어 스택: 이미지·영상을 화면 폭 가득, 세로로 나열(lazy loading)
3. 메타 한 줄: TYPE · YEAR · CLIENT · ROLE
4. 이전/다음 파일 이동 (← KDJ_013 / KDJ_015 →), 목록으로(`cd ..`)

### 정보 `/info` (브리프의 소개+연락을 한 페이지로 합침)
이름, 분야 한 줄, 클라이언트 목록, 이메일(선택 가능한 텍스트 + 복사 버튼), 인스타그램 링크.

### 404
`ERROR 404 — FILE NOT FOUND` + 커서, `cd ~/` 링크(메인)와 `ls /work` 링크.

> 브리프 사이트맵 대비 변경: `/about`과 `/contact`를 `/info` 하나로 합쳤어요. 글이 거의 없는 방향이라 두 페이지로 나누면 둘 다 비어 보이기 때문이에요.

## 공통 컴포넌트와 상태

| 컴포넌트 | 설명 | 상태 |
|---|---|---|
| TitleBar | 상단 고정 경로 + 메뉴 | 기본 / 스크롤 시 하단 선 표시 |
| NavLink | 대문자 모노 라벨 | 기본 / hover 반전 / 현재 페이지(앞에 ● 빨강) / focus 링 |
| MenuOverlay (모바일) | 전체 화면 파일 트리 메뉴 | 닫힘 / 열림(ESC·✕로 닫기, 포커스 가둠) |
| FolderTab | 분야 필터 | 기본 / hover / 선택(ink 반전) / focus |
| ViewToggle | GRID ↔ LIST | 선택 / 비선택 |
| FileCard | 썸네일 + 파일명 + 연도 | 기본 / hover·focus(캡션 반전) / 로딩(line 색 면) / 이미지 실패(파일명만) |
| FileRow | 목록 보기 한 줄: 번호, 파일명, 분야, 연도 | 기본 / hover 반전 / focus |
| MediaFrame | 이미지·영상 프레임 | 로딩(line 면) / 재생 / 정지 / reduced-motion 시 정지 상태로 시작 |
| Cursor | 깜빡이는 빨간 사각 커서 | 깜빡임 / reduced-motion 시 고정 |
| Button | 텍스트 버튼(복사, 이동) | 기본 / hover 반전 / active / disabled(회색) / focus |
| StatusBar | 푸터 | 기본 |

## 확인 사항
